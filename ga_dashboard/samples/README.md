Explanation of files
--------------------

These are example files to use, which have been anonymised.

* `df_agg_X_mockMultiUsers_1.csv`:

* `df_agg_X_mockMultiUsers_2.csv`: All the jobs per users (multiple lines per day when there are more than 1 job send during the day).

* `userDaily_mockMultiUsers_1.csv`: Same as `df_agg_X_mockMultiUsers_2,csv`, but aggregated per day and per user.

* `users_list.csv`: example list of users

* `sacct_output_single_user.txt`: example results from running the HPC `sacct` command for a single user.

* `example_sacctOutput_raw.txt`: similar to `sacct_output_single_user.txt`, but without `UID` or `User` fields

* `cluster_info.yaml`: example cluster configuration file
